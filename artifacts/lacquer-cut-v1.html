by STEMSMAG · Mastering Suite · WAV / MP3
Herramienta de ensayo / experimental

Este es un proyecto experimental construido sobre la Web Audio API, la API nativa del navegador para procesar audio en tiempo real. Funciona armando una cadena de nodos de audio (filtros, compresor, waveshaper de saturación, matriz estéreo y un limitador con anticipo/"lookahead") que procesan tu archivo en vivo mientras suena, y que también pueden renderizarse completos para exportar un WAV.

// LACQUER - CUT v1 no es un producto de entrega final profesional. Tampoco es:

  • Un restaurador de audio (no quita ruido, hum, clicks de vinilo, ni repara grabaciones dañadas).
  • Una herramienta de mezcla (no balancea pistas, no automatiza, no reemplaza tu DAW).

Lo que sí hace: te deja escuchar en tiempo real el efecto de una cadena de masterización simplificada (EQ, compresión de buss, saturación, imagen estéreo y limitador) sobre un render ya mezclado, para experimentar con presets y exportar un WAV procesado.

Si tu audio ya viene mal desde el origen — mal grabado, sin claridad en la mezcla, o con problemas de calidad — // LACQUER - CUT v1 no está diseñado para hacer milagros.

Notas técnicas y manual: arquitectura de la cadena de señal, cómo se calculan las métricas y guía de uso de cada módulo en el manual de // LACQUER - CUT v1 →
